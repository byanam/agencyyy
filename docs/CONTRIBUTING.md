# Contributing Guidelines

1. **Figma Fidelity**: All layout and component updates must match Figma specifications 1:1.
2. **Modular Code**: Keep styles and scripts modular under `src/styles/` and `src/js/`.
3. **Commit Messages**: Follow the Conventional Commits specification (`feat:`, `fix:`, `refactor:`, `style:`, `docs:`, `test:`, `chore:`).
