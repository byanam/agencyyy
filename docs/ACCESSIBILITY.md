# Accessibility & WCAG 2.1 Compliance

- **Semantic Landmarks**: `#wrap` with `role="main"`, `#nav` with `role="navigation"`, `#rcModal` with `role="dialog"`.
- **Keyboard Navigation**: Focus rings preserved, `Escape` key closes receipt modal dialog.
- **Screen Reader Announcements**: `aria-label` attributes on icon buttons and navigation elements.
