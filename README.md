# byanam — Legendary Agency Portfolio

🌐 **Live:** [https://byanam.github.io/agencyyy/](https://byanam.github.io/agencyyy/)

A high-performance creative agency portfolio built with vanilla HTML, CSS, and JavaScript — powered by Vite.

## ✨ Features

- **Atmospheric Scroll** — Infinite seamless loop with smooth inertial parallax
- **Storm Animation** — Multi-layered cloud parallax, canvas rain, thunder SFX, and lightning
- **4K Cloud Assets** — Photographic detail enhancement with dynamic range boosting
- **Smooth Nav Indicator** — Glassmorphic pill that slides between sections
- **Loading Screen** — Rotating stroke progress ring with brand umbrella
- **Background Audio** — Classical music + thunder SFX with browser autoplay handling
- **Contact Form** — Animated receipt-style inquiry modal
- **Responsive** — Scales cleanly from 320 px to 4 K displays

## 🛠️ Stack

| Layer | Technology |
|-------|-----------|
| Structure | Vanilla HTML5 |
| Styles | Vanilla CSS (inline `<style>`) |
| Logic | Vanilla JavaScript (inline `<script>`) |
| Build | Vite 8 |
| Assets | WebP (4 K, lossless-quality 95) |
| Audio | MP3 (classical + thunder) |

## 🚀 Getting Started

```bash
npm install     # install Vite dev dependency
npm run dev     # start local dev server at localhost:5173
npm run build   # build production bundle to dist/
npm test        # run unit tests
```

## 📁 Project Structure

```
├── index.html        # single-file app (HTML + CSS + JS)
├── public/
│   └── assets/       # images, audio, loader background
├── dist/             # production build output (git-ignored)
├── src/              # modular JS source (rain engine, etc.)
└── tests/            # unit + a11y + perf test suite
```
