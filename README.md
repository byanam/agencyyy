# byanam Portfolio Agency

🌐 **Live Website:** [https://byanam.github.io/agencyyy/](https://byanam.github.io/agencyyy/)

A modern, high-performance portfolio and agency website crafted with React 19, Vite, Tailwind CSS v4, Framer Motion, and Lenis smooth scrolling.

## ✨ Highlights
- **Fluid Kinetic Scrolling**: Powered by Studio Freight Lenis.
- **Micro-Animations & Transitions**: Smooth component reveals with Framer Motion.
- **Adaptive Theming**: Seamless dark and light modes with localStorage state persistence.
- **Responsive Layout**: Mobile-first architecture with dynamic hamburger drawer.
- **Componentized Design**: Modular architecture for showcase, services, FAQ, and contact sections.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Vanilla CSS Custom Properties
- **Motion**: Framer Motion
- **Scroll**: Lenis
- **Code Quality**: Oxlint

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
